# Pepito — Million Dollar UI Vision

**Статус:** живой документ, source of truth для UI/UX развития проекта.
**Последнее обновление:** 2026-04-20

---

## 1. Product Vision

Pepito — это не очередной Telegram-бот с кнопками. Это **персональный тренер для собаки**, который живёт в телефоне хозяина. Продукт должен ощущаться как дорогое приложение в App Store — тёплое, живое, сделанное с заботой.

### Три кита

**Warm.** Не холодный SaaS, не корпоративная "система управления задачами". Pepito знает имя твоей собаки, помнит её историю, радуется прогрессу. Каждый экран должен ощущаться как разговор с другом, а не работа с таблицей.

**Premium.** Детали имеют значение. Скругления углов, паузы между действиями, тактильный отклик на нажатие, анимация перехода. Premium — это не золотой градиент, это отсутствие ощущения "сделано на коленке".

**Alive.** Интерфейс реагирует. Streak растёт — экран это отражает. Задача выполнена — есть момент радости. Собака достигла milestone — что-то происходит визуально. Интерфейс должен жить вместе с тренировочным прогрессом.

### Чего НЕ должно быть

- Синие прямоугольные кнопки без контекста
- "Выберите пункт меню" как главный текст
- Telegram-дефолт без единого визуального решения
- Ощущение "бот написали за вечер"

## 2. UX Layers

Pepito существует в двух параллельных слоях. Они не конкурируют — они дополняют друг друга.

```
┌─────────────────────────────────────────┐
│         Telegram Web App                │  ← rich, visual, premium
│   (открывается кнопкой из бота)         │
│   dashboard / planner / profile         │
└────────────────┬────────────────────────┘
                 │ открыть / закрыть
┌────────────────▼────────────────────────┐
│         Inline Bot                      │  ← быстро, доступно всегда
│   (обычный чат с кнопками)              │
│   quick actions / AI / reminders        │
└─────────────────────────────────────────┘
```

**Правило разделения:** если действие занимает 1-2 тапа и требует только текста — это inline bot. Если нужна визуализация, форма с несколькими полями, график или что-то красивое — это Web App.

## 3. Inline Bot UX

Inline-бот — это **speed layer**. Пользователь открыл Telegram, сделал что нужно за 3 секунды, закрыл. Никаких лишних экранов.

### Главное меню

```
[ 🏋️ Тренировка на сегодня ] [ 📅 Недельный план ]
[ 📊 Статистика            ] [ 💬 Вопрос кинологу ]
[ 🐶 Мой питомец           ] [ ⚙️ Настройки        ]
[ ⭐ Получить Premium       ] [ 🛒 Магазин           ]
[ 🐾 Позови друга — бонус!                          ]
```

Приветственный текст:
```
🐾 Привет, Иван! Бруно ждёт тренировку.
🔥 Серия: 5 дней подряд

Выбери раздел:
```

Streak видно сразу. Имя питомца — в тексте, не в кнопке.

### Тренировка (inline)

- Список задач с кнопками ⬜/✅
- При нажатии: `cb.answer("✅ Выполнено!")` или `cb.answer("↩️ Снято")` — тактильный момент
- После всех задач: `🎉 Тренировка завершена! Серия: 6 дней 🔥`
- Кнопка ℹ️ у каждой задачи → AI-объяснение
- "🔄 Новый план" с подтверждением: "Сгенерировать новый план? Текущий прогресс сбросится. [Да] [Нет]"

### Weekly Plan (inline)

- Навигация ◀ День 3 из 7 ▶
- Toggle задач — те же ⬜/✅
- После завершения дня: `🎉 День выполнен!` + shop-кнопка

### AI Coach (inline)

- Быстрый Q&A в чате
- История диалога в рамках сессии
- Кнопка "Новый вопрос" для сброса контекста
- Rate limit: тихое сообщение "Лимит 5 вопросов на сегодня" + кнопка Premium

### Settings Submenu (inline)

```
[ ⏰ Напоминания          ]
[ ✏️ Редактировать профиль ]
[ ❓ Помощь               ]
[ 🔙 В главное меню       ]
```

Настройки — простой список. Без анимаций, без богатства. Скорость важнее.

### Reminders (inline)

- Ввод времени `HH:MM UTC`
- Подтверждение: "Готово! Напоминание в 09:30 UTC ⏰"
- Ошибка: "Неверный формат. Введи время как 09:30"

### Premium / Shop / Referral entry points (inline)

Это **точки входа**, а не полные экраны. Нажал — открылся Web App (в будущем) или упрощённый inline-экран (сейчас).

- Premium: описание + Telegram Stars invoice
- Shop: 4 кнопки с UTM-ссылками на pepitopet.ru
- Referral: личная ссылка + счётчик + прогресс до milestone

## 4. Telegram Web App UX

Web App — это **premium layer**. Открывается через кнопку `[🌟 Открыть Pepito App]` из главного меню или из premium-экрана. Визуально богатый, но не медленный.

### Dashboard (главный экран Web App)

```
┌──────────────────────────────────────┐
│  🐾 Привет, Иван!                    │
│  Бруно / Лабрадор / 2 года           │
│                                      │
│  ┌──────────────┐  ┌──────────────┐  │
│  │ 🔥 Streak    │  │ ✅ Выполнено  │  │
│  │   12 дней   │  │  47 задач    │  │
│  └──────────────┘  └──────────────┘  │
│                                      │
│  [████████░░] 8 из 10 задач (нед.)   │
│                                      │
│  Тренировка сегодня:                 │
│  ┌────────────────────────────────┐  │
│  │ ⬜ Отработка команды "Сидеть"  │  │
│  │ ✅ Прогулка 30 мин             │  │
│  │ ⬜ Работа с поводком           │  │
│  └────────────────────────────────┘  │
│                                      │
│  [ ➕ Начать тренировку ]            │
└──────────────────────────────────────┘
```

Карточки со статистикой. Progress bar по неделе. Список задач как живые карточки, не кнопки.

### Weekly Planner (Web App)

- Горизонтальный скролл по дням: Пн Вт Ср Чт Пт Сб Вс
- Активный день — выделен цветом
- Каждый день — список задач с drag-and-drop (или просто toggle)
- Calendar heatmap внизу: последние 30 дней, цвет = % выполнения

### Profile Editor (Web App)

Форма вместо FSM-диалога в чате:

```
┌──────────────────────────────────────┐
│  🐾 Профиль питомца                  │
│                                      │
│  Имя:        [Бруно          ]       │
│  Порода:     [Лабрадор       ]       │
│  Возраст:    [2 года ▼       ]       │
│  Вес:        [28 кг          ]       │
│  Уровень:    [Начинающий ▼   ]       │
│  Темперамент:[Активный ▼     ]       │
│                                      │
│  [ Сохранить ]  [ Отмена ]           │
└──────────────────────────────────────┘
```

Одна форма вместо 10 шагов FSM. Редактирование любого поля без перезапуска диалога.

### Premium Landing (Web App)

Красивый onboarding в Premium при первом открытии:

```
  ⭐ Pepito Premium

  [анимация: золотые частицы или лапки]

  Безлимитный AI-кинолог
  Персональные рекомендации Бруно
  Глубокий анализ прогресса
  Приоритетная поддержка

  [ Оформить за X ⭐ Stars ]
  [ Узнать больше ]
```

Не список фич с буллетами. Эмоциональный экран "ты открываешь что-то особенное".

### Referral Center (Web App)

```

  [прогресс-бар: 3 из 5 до следующего уровня]

  Твоя ссылка:

  10 друзей → +30 дней Premium
  25 друзей → +90 дней Premium

  Приглашено: 3 | Ждут: 2 до следующего уровня
```

Визуальный прогресс, не просто цифра.

## 5. Visual Design Direction

### Принцип: Warm Premium Pet-Tech

Не SaaS. Не медицинское приложение. Не game. Что-то между **Bear Notes** и **Duolingo** — функциональное, но живое и тёплое.

Референсы по настроению:
- Bear Notes — чистота, тёплые тона, уважение к контенту
- Duolingo — радость от прогресса, живые реакции
- Linear — точность и скорость, но без холода
- Locket Widget — интимность, "это для меня и моей собаки"

### Атмосфера

Представь: **осеннее утро, ты идёшь с собакой в парке, смотришь в телефон.** Интерфейс должен ощущаться именно так — тепло, не спеша, с заботой. Не офисный дедлайн.

### Glassmorphism — применять аккуратно

Glassmorphism уместен для:
- Карточек поверх фонового градиента на dashboard
- Premium-экрана (ощущение "стеклянный premium badge")
- Модальных окон поверх контента

Glassmorphism НЕ уместен для:
- Навигационных элементов (плохо читается)
- Мелкого текста
- Inline-бота (там его нет)

## 6. Design System

### Palette

```
Primary
  --pepito-amber:     #F5A623   ← тёплый янтарь, основной акцент
  --pepito-brown:     #8B5E3C   ← земля, доверие
  --pepito-cream:     #FDF6EC   ← фоновый тёплый белый

Success / Streak

  --pepito-fire:      #FF6B35   ← streak, энергия

Premium
  --pepito-gold:      #FFD700   ← premium-акцент
  --pepito-gold-soft: #FFF3CD   ← premium-фон

  --text-secondary:   #6E6E73

  --text-xs:   12px / 1.4

  --text-lg:   18px / 1.5

### Spacing

```
Base unit: 4px

--space-1:   4px
--space-2:   8px

--space-6:   24px   ← между секциями
--space-8:   32px   ← крупные отступы
--space-12:  48px

### Card Style

```css
/* Стандартная карточка (light mode) */
.card {
  background: #FFFFFF;
  border-radius: 20px;
  padding: 16px;
  box-shadow: 0 2px 12px rgba(0,0,0,0.06);
}

/* Glass карточка (dark mode / premium экраны) */
.card-glass {
  background: rgba(255, 255, 255, 0.08);
  border: 1px solid rgba(255, 255, 255, 0.15);
  border-radius: 20px;
  padding: 16px;
  backdrop-filter: blur(20px);
  -webkit-backdrop-filter: blur(20px);
}

/* Premium card */
.card-premium {
  background: linear-gradient(135deg, #FFF3CD 0%, #FDF6EC 100%);
  border: 1px solid #FFD700;
  border-radius: 20px;
}
```

### Icon Style

- Стиль: rounded, filled (не outline, не sharp)
- Референс: SF Symbols rounded, Phosphor Icons (fill variant)
- Размеры: 20px (inline), 24px (menu), 32px (dashboard cards), 48px (onboarding)
- Не использовать: Material Design sharp icons, emoji как единственные иконки в Web App

### Motion Principles

```
Принцип: движение должно быть значимым, не декоративным

Durations:
  --motion-quick:   150ms  ← hover, toggle states
  --motion-base:    250ms  ← page transitions, card появление
  --motion-slow:    400ms  ← onboarding, celebrate moments

Easing:
  --ease-out:  cubic-bezier(0.16, 1, 0.3, 1)   ← появление элементов
  --ease-in:   cubic-bezier(0.4, 0, 1, 1)       ← уход элементов
  --ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1)  ← bounce для celebrate

Celebrate moments (streak, milestone):
  - Scale: 1 → 1.05 → 1 (150ms spring)
  - Confetti или pulse на иконке 🔥
  - Не использовать на обычных действиях — только на достижениях
```

## 7. Rollout Plan

### Stage 1 — Polish Inline Bot UX
*Текущий слой, small diffs, autoresearch-цикл*

Задачи (в порядке приоритета):
1. `cb.answer("✅ Выполнено!")` при toggle задачи — 1 строка на хэндлер
2. Streak в приветственном тексте главного меню — 1 запрос в БД
3. Подтверждение "🔄 Новый план" — 1 FSM state или callback с параметром
4. Onboarding progress bar "Шаг X из 10" — в каждый шаг онбординга
5. Кнопка "Новый вопрос" в AI-кинологе — сброс FSM-истории без выхода

Критерий готовности Stage 1: все UX-полировки из CLAUDE.md backlog реализованы.

### Stage 2 — Premium Inline Surfaces
*Визуальное отличие premium/free в рамках inline-бота*

1. Premium-экран: эмоциональный текст вместо списка фич
2. Статистика: прогресс-бар к следующему milestone рефералов
3. AI-анализ: premium-версия с заголовком и структурой
4. Premium badge в приветственном тексте меню ("⭐ Premium до 15 мая")

Критерий готовности Stage 2: premium-пользователь видит отличие от free на каждом ключевом экране.

### Stage 3 — Telegram Web App MVP
*Новый frontend, открывается кнопкой из бота*

Scope MVP — один экран: **Dashboard**
- Карточки streak + выполнено задач
- Список задач сегодня с toggle
- Кнопка "Открыть в боте" для действий

Технический стек: Svelte (или vanilla JS если хочется минимализм) + Telegram WebApp JS API.
Размещение: nginx как новый сервис в podman-compose.yml (отдельный контейнер, не трогать бота).

Критерий готовности Stage 3: пользователь может открыть Dashboard из бота, видит свой прогресс.

### Stage 4 — Full Premium Design System
*После того как Web App MVP работает и нравится*

1. Внедрить цветовую палитру и типографику из этого документа
2. Glass-карточки на premium-экранах Web App
3. Motion: celebrate moments при streak/milestone
4. Weekly Planner в Web App
5. Profile Editor в Web App (замена FSM)
6. Premium Landing в Web App
7. Referral Center в Web App

Критерий готовности Stage 4: Pepito Web App можно показать как продуктовое демо.

## 8. Guardrails

### Inline Bot = Speed and Clarity

- **Не пытаться имитировать glassmorphism через inline-кнопки.** Telegram не рендерит CSS. Кнопки — это кнопки.
- Максимум текста на экране: 4-5 строк + клавиатура. Больше — пользователь не читает.
- Не злоупотреблять emoji как единственным visual language — они теряют значение.
- Каждый экран должен иметь одно главное действие. Не 8 кнопок одного уровня.
- FSM-диалоги — только там, где нет другого выхода. Profile editor → Web App.

### Web App = Rich Premium Visuals

- Web App открывается только по явному действию пользователя (кнопка). Не автоматически.
- Все данные — через бот API или прямой запрос к backend. Не хранить секреты во frontend.
- Web App не заменяет бота полностью — он дополняет. Критические действия (AI, reminders) остаются в боте.
- Glassmorphism применять только там, где есть фоновый контент (blur нужен context). На пустом белом фоне — это просто серая рамка.
- Анимации — только если не мешают производительности. На слабых устройствах — отключать через `prefers-reduced-motion`.

### Общие

- Не переходить к Stage N+1, пока Stage N не завершён и не проверен пользователем.
- Каждое изменение — через autoresearch-цикл: propose → patch → judge → keep/discard.
- Дизайн-решения фиксировать здесь до реализации. Не реализовывать без зафиксированного плана.
- Этот документ обновлять при каждом завершении этапа.
