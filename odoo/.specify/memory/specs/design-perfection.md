# Spec: Дизайн pepitopet.ru — доведение до совершенства

**Status**: In Progress | **Created**: 2026-05-14 | **Owner**: Agent

---

## Цель

Привести сайт pepitopet.ru к профессиональному, целостному виду в стиле "мексиканская фиеста для питомца". Каждая страница должна выглядеть как единое дизайн-решение, а не набор дефолтных Odoo-блоков.

---

## Scope

### Страницы
- `/` — Главная
- `/shop` — Магазин
- `/shop/<id>` — Карточка товара
- `/oferta`, `/contactus`, `/privacy` — Статичные страницы

### Вне scope
- Бэкенд Odoo (заказы, склад, платёжные системы)
- Telegram-бот

---

## Требования

### REQ-01: Главная страница
- **Блок 1 (Hero)**: Полноэкранный баннер, заголовок на Playfair Display, кнопки rust + ghost.
- **Блок 2 (Преимущества)**: Три карточки с иллюстрациями (установлены: Мясо, Ручная работа, Доставка). Белые карточки, иконка вверху, текст внизу. ✅ Выполнено.
- **Блок 3 (Masonry)**: "Лакомства для Amigos" и "Кормовые культуры" — качественные фото, текст читаем.
- **Блок 4 (Динамические товары)**: "Наши лакомства" показывает говяжьи лакомства с ценами. ✅ Выполнено.
- **Блок 5 (CTA)**: "Выбор владельцев кесло" — текст и кнопка. Проверить верстку.
- **Блок 6 (CTA-баннер)**: "Натуральный выбор" — тёмный блок, кнопка в каталог. ✅ OK.

### REQ-02: Шапка
- Логотип Pepito (собака с сомбреро) в шапке. ✅ Выполнено.
- Логотип 72px высотой. ✅ Выполнено.
- Навигация: Главная / Магазин / Блог.

### REQ-03: Магазин `/shop`
- Категориальные вкладки "Для собак" / "Кормовые насекомые" видны.
- Карточки товаров: фото, название, цена rust-цветом. Hover-эффект.
- Хлебные крошки "Все товары" (не "All products"). ✅ Выполнено.
- Нет товаров с ценой 0 или 1 руб. ✅ Выполнено.

### REQ-04: Карточка товара
- Название на Playfair Display.
- Цена крупная, rust-цвет.
- Описание товара присутствует (для всех опубликованных). ✅ Выполнено (8 товаров добавлено).
- Кнопки "В корзину" / "Купить сейчас" — скруглённые, rust.

### REQ-05: Футер
- Без плейсхолдеров (ИНН, "укажите реквизиты"). ✅ Выполнено.
- Три колонки: Каталог / Информация / Доставка.
- Телефон, копирайт.

### REQ-06: Типографика и цвета
- Playfair Display для всех h1-h3.
- Кнопки pill-shape (border-radius: 100px).
- Цены: `$color-rust`.
- Фон страниц: `$color-cream` (#FDF6EE).

## Критерии готовности (Definition of Done)

1. Скриншоты всех страниц показывают единый дизайн в цветах бренда.
2. `./judge.sh` — exit 0.
3. Нет английских строк на русскоязычных страницах.
4. Мобильная версия не ломается (viewport 375px).
5. Все опубликованные товары имеют описания и корректные цены.
